# 🐝 HoneyChain

### 🍯 From Hive to Home — Every Drop, Verified.

**Smart India Hackathon 2026 • Problem ID 26021**

HoneyChain is a modern **AgriTech + FoodTech** platform that connects **smart hive monitoring, AI analysis, honey quality, traceability, blockchain concepts, and QR verification** into one ecosystem.

## ✨ What HoneyChain Does

### 🐝 For Sellers

* 📊 Smart hive monitoring
* 🤖 AI-powered hive health simulation
* 🍯 Digital honey batch management
* ✏️ Edit & update batch information
* 🧪 Quality verification records
* 🔗 Honey traceability timeline
* 📱 QR code generation
* 📈 Production & hive analytics
* 🔔 Alerts & notifications

### 🍯 For Buyers

* 🔎 Search by Batch ID
* 📱 QR-based verification
* ✅ Verify honey status
* 🌱 View honey origin
* 🧪 Check quality information
* 🗺️ Explore the honey journey
* 📋 View verification history

---

## ⭐ Core Demo

The entire prototype revolves around:

**`HC-2026-00125`**

A seller can change:

```text
Mustard → Litchi
42 kg → 55 kg
```

💾 Changes are saved using **LocalStorage**.

The buyer searches the same Batch ID and instantly sees the **latest seller information**.

> 🔄 **Seller → Shared Batch → Buyer**

This is the core HoneyChain demonstration.

---

## 🛠️ Tech Stack

**Frontend:** HTML5 • CSS3 • Vanilla JavaScript
**Storage:** LocalStorage
**Charts:** Chart.js
**QR:** JavaScript QR Library

No backend. No framework. Fully static and deployable.
